# Carrollton Healthcare Website

This project is a simple healthcare directory website for Carrollton, Georgia. It is designed to help users find healthcare information, providers, and services in a clear and organized way.

## Project Structure

- index.html Main homepage
- pages/ Contains all additional site pages
  - contact.html Contact form page
  - success.html Form submission confirmation page
  - providers.html Providers listing page
  - provider.html Individual provider page
  - emergency.html Emergency services page
  - faq.html Frequently asked questions page
  - accessibility.html Accessibility features page
- css/style.css Global styling for the entire site
- javascript/script.js Handles accessibility settings and UI behavior
- images/ Contains images used throughout the site

## How to Run

Open index.html in a web browser.
